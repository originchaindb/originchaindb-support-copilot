# BeaconDesk: deleted tasks and account recovery

Deleted tasks remain in the project trash for thirty days.
Project members with edit access can restore a task from Project > Trash.
After thirty days, the task is permanently removed and cannot be restored
through the application.

To reset a password, select Forgot password on the sign-in page.
Enter the account email address and follow the emailed reset link.
Password-reset links expire after one hour. Request a new link if it expires.

If a reset email does not arrive, check spam and verify the email address.
Contact the workspace owner if access is still unavailable.
This guide does not describe workspace backups or a disaster-recovery SLA.
