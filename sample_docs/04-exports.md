# BeaconDesk: export your workspace

Workspace owners can export data from Settings > Data > Export workspace.
The export contains projects and tasks as CSV files in a ZIP archive.
Attachments are listed by filename; attachment binaries are not included.

When the export is ready, BeaconDesk sends a download link to the workspace
owner's email address. The download link expires after twenty-four hours.
If the link expires, create another export from the same Data page.

Exports reflect a snapshot taken when the export job starts. Tasks changed
after that point will appear in a later export. Exporting does not remove
or modify the original workspace data.
